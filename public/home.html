Веб-разработка: начальный уровень. Предлагаю услуги по созданию небольших сайтов, лендингов, форм обратной связи. Работаю с базами данных, осуществляю вёрстку по макетам Figma.

Опыт написания сайтов на PHP, MySQL, HTML, CSS, Bootstrap. Пишу код с помощью ИИ (глубокое понимание промптов), полностью контролирую результат и адаптирую под задачи клиента.

Верстаю макеты из Figma — как с Bootstrap, так и без него (чистый CSS, Flexbox, Grid).
